# LTI-bff integration for a simple browser based quiz

Somwewhat vibe-coded MVP.

Example launch:
```
http://localhost:3001/lti/launch-as?user_id=1&redirect_uri=http://localhost:3000/
```


Inspect keys:
```
http://localhost:3001/lti/jwks
```
